# 카페 관리 시스템 클래스다이어그램

```mermaid
classDiagram
    class Kiosk {
        -Cafe cafe
        -Customer customer
        +Kiosk(Cafe cafe, Customer customer)
        +StartOrder(Order myOrder) bool
        -SelectMenu(Order myOrder) void
        -ManageCart(Order myOrder) void
        -ProcessKioskPayment(Order myOrder) bool
        +GetIntInput()* int
    }

    class CafeManagementSystem {
        -Cafe cafe
        -int nextOrderNumber
        +Run() void
        -ShowMainMenu() void
        -RegisterOrder() void
        -KioskOrderMenu() void
        -CreatePaymentRecord(int amount) Payment
        -CancelOrderRecord() void
        -StockMenu() void
        -EmployeeMenu() void
        -RegisterEmployee() void
        -RegisterEmployeeSchedule() void
    }

    CafeManagementSystem --> Cafe
    CafeManagementSystem --> Kiosk
    Kiosk --> Cafe
    Kiosk --> Customer
    Kiosk --> Order
```

## 읽는 순서

1. `Program`이 `Cafe`와 `CafeManagementSystem`을 만든다.
2. `CafeManagementSystem`은 사용자의 입력을 받고 `Cafe` 기능을 호출한다.
3. `Cafe`는 메뉴, 직원, 주문, 재고, 매출 정보를 관리한다.
4. `Menu`는 `Recipe`를 가지고, `OrderLine`은 메뉴와 수량을 저장한다.
5. `Order`는 여러 `OrderLine`과 `Payment`를 가진 주문 기록이다.
6. `Employee`는 여러 `WorkSchedule`을 가지고 현재 근무 상태를 계산한다.
